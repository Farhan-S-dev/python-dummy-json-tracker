# Project 2: Dummy JSON API Data Tracker

This project explores working with JSON data from public APIs. It automates fetching data and parsing API responses.

## 🚀 What it does
- Fetches data from a dummy API endpoint using the `requests` library.
- Parses JSON responses to extract specific information.

## 🛠️ Tech Stack
- **Language:** Python 3
- **Libraries:** `requests`, `json`

## 💡 Key Skills
- Working with REST APIs (`GET` requests).
- Handling and parsing JSON data structures in Python.
